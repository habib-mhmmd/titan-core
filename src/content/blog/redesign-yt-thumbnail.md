### Description
This personal project focuses on redesigning YouTube video thumbnails for David Alfa Sunarna. The main objective of this project is to create thumbnails that are more eye-catching and able to grab viewers' attention at first glance, while also strengthening the visual identity of their video content. The redesign process involves the use of more contrasting typography, improved visual composition, and the application of striking color schemes to make the video's message instantly recognizable to the audience.
